# School Timetable Generator
## Description
A simple Python program that generates a random school timetable and saves it to a text file.
## Features
- Randomly assigns subjects to days.
- Displays the timetable in the terminal.
- Saves the timetable as `timetable.txt`.
## Technologies Used
- Python 3.13
## How to Run
```bash
python timetable.py
```
## Example Output
==============================
   SCHOOL TIMETABLE
==============================
Monday      : Physics
Tuesday     : English
Wednesday   : Math
Thursday    : Biology
Friday      : Chemistry
Saturday    : Computer Science
